Relationships Summary

Relationship Type Description
User → SignPredictionHistory One-to-Many A user can have many sign language predictions saved
User → TranslationHistory One-to-Many A user can have many speech-to-sign translations saved
User → PasswordResetCode One-to-Many A user can request multiple password reset codes
User → EmailVerificationCode One-to-Many A user can have multiple email verification codes
User → Event One-to-Many An admin user can author multiple Deaf Hub events
PredictASLView → TFLiteASLModel Dependency View uses singleton model instance for inference
PredictASLView → Preprocessor Dependency View uses preprocessing pipeline before prediction
translate_audio → SignEngine Dependency View uses sign engine for video stitching and upload
SpeechToSignTranslator → WhisperTranscription Dependency Speech translation uses Whisper for audio transcription
SpeechToSignTranslator → TranslationHistory Dependency Speech translation saves translation results and video URLs to history

Design Patterns Used

Pattern Where Purpose
Singleton TFLiteASLModel Load the TFLite model once into memory, reuse across all requests
Signal (Observer) send_otp_on_signup Automatically send verification email when a new user is created
Strategy IsAdminUserOrReadOnly Pluggable permission logic — admin can write, others read-only
Template Method DRF Generic Views Override hooks like get_queryset() and perform_create()
Facade text_to_sign() Single entry point that hides text normalization, video stitching, and cloud upload

Key Classes Description

Class Layer Responsibility
User Model Custom user model extending Django's AbstractUser with email as primary login field, role-based access (user/admin), and profile fields
SignPredictionHistory Model Stores sign-to-text AI predictions with confidence scores and optional video recordings
TranslationHistory Model Stores speech-to-sign translations with favorite toggle and Cloudinary video URLs
TFLiteASLModel Service Singleton wrapper around TensorFlow Lite interpreter for 50-word ASL classification
WhisperTranscription External Service Handles speech recognition for audio inputs in speech-to-sign translation
SpeechToSignTranslator Service Coordinates Whisper transcription, sign video generation, and translation history storage
Preprocessor Service Normalizes 114 MediaPipe landmarks with dominant hand detection and motion features (position + velocity + acceleration)
SignEngine Service Converts text to sign language video by mapping words to Cloudinary clips and stitching with FFmpeg
Event Model Deaf community events with Cloudinary media storage, admin-only creation
